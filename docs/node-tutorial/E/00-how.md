# E00 怎么用这套题

题库按主题拆开。每题包含难度、考察点、参考答案、易错点、追问。参考答案按 Node.js **22.23.4** 的实测行为来写。版本差异写在 [版本说明](../00-versions-and-how-to-run.md)。

## 使用方式

1. 先自己讲满三分钟，再打开参考答案。对着答案改自己的表述，而不是背下来。
2. 顺序题要能在纸上写出队列。讲“看情况”时，把情况说成 CJS 顶层、ESM 入口、I/O 回调或 Promise 回调中的哪一种。
3. 追问通常在考边界：多进程、崩溃、重复执行、谁先谁后不稳定。
4. 手写题对应 `examples/node-tutorial/E/` 与 D 目录里的脚本。讲完可以跑 `node examples/node-tutorial/run-all.mjs`。

## 评分时面试官在听什么

见 [E12](./12-scoring.md)。短答案如果漏掉“主线程”“不共享堆”“至少一次”“签名不是加密”，会被追问。把这四句放进相关题的第一段。

## 难度

- 初级：API 能用对
- 中级：能解释失败和资源
- 高级：能把运行时行为和系统设计接在一起
