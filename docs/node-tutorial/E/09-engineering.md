# E09 工程与数据

### Q1. 配置为什么在启动时失败？

- 难度：初级
- 考察点：失败要早
- 参考答案：环境变量是字符串。启动时检查存在性、整数范围和枚举值，失败就不要 `listen`。请求中途才发现没有数据库地址，会留下半初始化状态。`loadEnvFile` 不覆盖已有变量，未加引号的 `#` 是注释。
- 易错点：给缺失端口一个默认 3000，生产悄悄听错端口。
- 追问：秘密放哪？部署系统注入的环境变量或秘密管理服务。不进 git。

### Q2. 测试应该打到真实网络吗？

- 难度：初级
- 考察点：确定性
- 参考答案：单元测试不打。用 `mock.fn` 或注入的客户端。教程的 HTTP 示例起 `127.0.0.1` 上的服务器，测完 `close`。`node:test` 在 22 是正式的。`mock.timers` 仍有实验警告，时间用参数或注入的 `set`/`clear`。
- 易错点：忘了 `await`，用例在断言前结束。
- 追问：怎样测 413？发送超过上限的正文，断言状态码，而不是断言客户端抛了网络错误。

### Q3. 事务里能 `await fetch` 吗？

- 难度：中级
- 考察点：锁的时间
- 参考答案：不要。事务持有的锁或连接会覆盖整个 HTTP 往返。先调用外部服务，再开短事务写入结果；或者用出箱表让工作者在事务外发送。示例的 SQLite 事务只包住两次 `insert`。
- 易错点：为了“原子”把所有步骤放进一个数据库事务。
- 追问：同步 `DatabaseSync` 的代价？调用期间主线程不能处理其他请求。

### Q4. 优雅退出的顺序？

- 难度：中级
- 考察点：信号与连接
- 参考答案：收到 `SIGTERM` 后 `server.close()`，停止领取新任务，等待在途工作但设置上限，然后关数据库。示例里慢请求在 `close` 之后仍返回 `slow`，新的 `fetch` 失败。`SIGKILL` 不能捕获。不要在信号里直接 `process.exit()`，那会跳过异步收尾。
- 易错点：只 `close` 服务器，数据库池还在，进程不退出。
- 追问：存活检查和就绪检查？存活只证明进程能响应。就绪才检查数据库。存活里查下游会导致级联重启。

### Q5. 迁移怎样发布？

- 难度：高级
- 考察点：兼容
- 参考答案：先加新结构并保持旧代码能跑，再发布读写新结构的代码，最后删旧结构。破坏性迁移和只认新结构的代码放在同一次发布，回滚时读不懂数据。多实例同时启动时，迁移需要锁。
- 易错点：启动时每个进程无锁地 `ALTER TABLE`。
- 追问：幂等键存在什么时候删？业务允许重复的窗口结束之后，按过期时间清理。

### Q6. 日志里最少有哪些字段？

- 难度：初级
- 考察点：可检索
- 参考答案：时间、级别、消息、请求号、错误码。请求号放在 `AsyncLocalStorage`，避免 `await` 之后串号。示例两条重叠日志的 `requestId` 分别是 `req-a` 和 `req-b`。不打印令牌和环境变量。栈留在服务端。
- 易错点：每个函数参数都加 `requestId`，有一层漏了就断。
- 追问：指标标签能放用户 ID 吗？不能。基数会爆。用户 ID 放日志。
