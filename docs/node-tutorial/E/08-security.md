# E08 安全

防御清单见 [D11](../D/11-security.md)。回答时讲清输入从哪来、怎样进到敏感 API、用哪个 API 接住。

### Q1. 路径穿越怎么防？

- 难度：中级
- 考察点：`path.resolve` 的绝对路径规则
- 参考答案：`path.resolve(root, userPath)` 之后用 `path.relative`。相对结果以 `..` 开头或成为绝对路径就拒绝，错误码 `E_PATH_ESCAPE`。`../secret`、`/etc/passwd`、`a/../../secret` 都要拒绝。`a/../b.txt` 仍在根内，可以允许。符号链接要在打开后再检查真实路径。
- 易错点：只删除字符串里的 `..`。编码和重复斜杠会绕过。
- 追问：`path.join` 为什么不够？它会按 `..` 向上走，而且不会替你对比根目录。

### Q2. SQL 注入在示例里怎样被参数挡住？

- 难度：中级
- 考察点：预编译
- 参考答案：`WHERE name = ?` 配 `get("ada' OR '1'='1")` 查找的是这个名字本身，结果是 `undefined`。拼进 SQL 文本则会改变语句结构。`exec` 只用于固定语句。`node:sqlite` 的行对象原型是 `null`。
- 易错点：先替换引号再拼接。
- 追问：`LIKE` 呢？通配符也要当数据，模式用参数，不要让用户控制语句结构。

### Q3. JWT 的 `alg: none` 为什么危险？

- 难度：高级
- 考察点：算法固定
- 参考答案：如果服务器按头里的算法执行，攻击者可以把算法改成 `none` 并去掉签名。示例见到 `alg !== 'HS256'` 就返回 `reason: 'alg'`，不进入比较。签名是 HMAC，载荷仍是可读的 base64url。改载荷不改签名会得到 `sig`。`timingSafeEqual` 要求等长。
- 易错点：说 JWT “加密了用户 id”。
- 追问：怎样注销？短寿命加刷新令牌，或服务器会话。纯 JWT 在过期前无法单方面作废，除非另建吊销表。

### Q4. 口令能用 SHA-256 吗？

- 难度：中级
- 考察点：慢哈希
- 参考答案：不能。SHA-256 太快。用 `scrypt`（本版本有）或 Argon2（本版本的 `node:crypto` 没有 argon2 函数）。每个口令独立的盐，盐来自 `randomBytes`。比较结果用 `timingSafeEqual`。
- 易错点：加一个固定盐就说足够。盐要每条记录不同，用来防止预计算表，慢哈希用来提高猜测成本。
- 追问：`Math.random` 能做重置码吗？不能。用 `randomBytes` 或 `crypto.randomUUID`。

### Q5. 服务端请求伪造怎么收？

- 难度：高级
- 考察点：允许列表
- 参考答案：解析用户 URL，只允许预期的协议和主机。拒绝把原始字符串直接交给 `fetch`。只屏蔽 `127.0.0.1` 不够，还有其他本机地址、DNS 重新指向和重定向。生产策略是允许列表，而不是越来越长的拒绝列表。
- 易错点：跟随所有重定向。
- 追问：`#` 在 dotenv 里呢？未加引号的 `#` 是注释，连接串要加引号。这和 SSRF 无关，但是配置注入的同类问题：输入被另一层语法解释。

### Q6. `--permission` 保护什么？

- 难度：中级
- 考察点：纵深
- 参考答案：Node 进程内的允许列表。示例在只允许读 `/tmp` 时读 `/etc/hostname`，得到 `ERR_ACCESS_DENIED`。不加旗标时 `process.permission` 是 `undefined`。它不代替参数化查询、路径检查和操作系统用户。
- 易错点：把它当成应用防火墙。
- 追问：容器还要做什么？非 root 用户、只读根文件系统、内存和 CPU 限制、最小的网络权限。
