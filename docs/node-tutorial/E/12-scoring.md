# E12 追问与评分

面试里加分的是边界，不是名词数量。下面每条都是“答完主问题之后，对方很可能接着问”的方向。

## 运行时

| 你刚说了 | 准备好的下一句 |
| --- | --- |
| Node 是单线程 | 主线程跑 JavaScript。libuv 线程池跑 fs 和慢哈希。Worker 是别的 isolate |
| nextTick 在 Promise 前 | 这是 CJS 顶层和 I/O 回调。ESM 入口和 Promise 回调里，微任务先排完 |
| setImmediate 比 setTimeout 早 | 这是在 I/O 回调里。主模块两种顺序都会出现 |
| 异步 fs 不阻塞 | 不阻塞主线程。在 22.23.4 上它仍占用线程池，池子满了会排队 |
| 未处理拒绝只是警告 | Node 22 默认让进程非 0 退出 |

## 数据与正确性

| 你刚说了 | 准备好的下一句 |
| --- | --- |
| 写了事务 | 事务里不等待外部 HTTP。失败就回滚 |
| 队列保证送达 | 至少一次。处理函数要幂等。可见性超时要长于执行时间 |
| 用了 JWT | 只是签名。算法钉死。过期前不能单方面注销 |
| 内存缓存 | 有容量上限。多副本不一致。不是系统的事实来源 |
| 限流 | 单进程桶不是全局限流 |

## 失败

| 你刚说了 | 准备好的下一句 |
| --- | --- |
| 会重试 | 只重试幂等操作，有次数、退避和抖动 |
| 优雅退出 | `close` 之后旧请求跑完，新连接拒绝，并且有超时 |
| 类型是 TypeScript | 22 的剥离不检查类型，`enum` 默认跑不了 |
| 有健康检查 | 存活不访问数据库，就绪才访问 |

## 评分档

**初级通过**：能写出读文件、起 HTTP、用 `async/await` 接住拒绝，知道参数化查询和不要把用户字符串交给 shell。

**中级通过**：能画出事件循环阶段，说清 CJS 与 ESM 入口的队列差别，解释背压、线程池、`AbortSignal`，并给短链或上传一个有上限的设计。

**高级通过**：能把“至少一次、幂等、可见性、多副本不共享堆、签名不是加密、测量先于优化”放进同一道设计题，并指出示例代码离生产还差持久化、允许列表和退出超时中的哪几项。

## 本教程没有替你验证的事

- Node 26 上的新 API。选型可以选 26，行为要重跑 `examples/node-tutorial/run-all.mjs`
- `node:sqlite` 去掉实验警告的版本。22.23.4 仍会警告
- 分布式队列、对象存储、OpenTelemetry 收集器的具体配置。正文只规定它们在系统里的职责

这些缺口要在面试里主动说“我没有在那个版本上跑过”，然后给出你会怎样验证：同一套断言换运行时再跑，看退出码和警告。
