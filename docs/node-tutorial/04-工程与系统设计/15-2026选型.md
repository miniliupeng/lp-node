# 2026 选型

核对日期 2026-11-07。数字以 [版本](../00-版本.md) 为准。

| 选择 | 在这一天的建议 |
| --- | --- |
| 新服务的 Node 主版本 | 26（Lithium，Active LTS）。上线前用该版本重跑测试 |
| 本教程和已核对的 API | 22.23.4（Jod，Maintenance，支持到 2027-04-30） |
| 还在 20 上的服务 | 20 已于 2026-04-30 结束支持，应迁走 |
| 语言 | 普通 JavaScript 即可。需要类型时用 TypeScript，运行前用 `tsc --noEmit` 检查 |
| 直接 `node file.ts` | 22.23.4 会剥离可擦除语法，不检查类型。`enum` 需要实验开关 |
| HTTP | 标准库 `node:http` 足够做小服务。框架解决路由和中间件，不改变事件循环 |
| 数据库 | `node:sqlite` 仍是实验 API。生产数据用已稳定的驱动，参数化查询 |
| 测试 | `node:test` 稳定。`mock.timers` 和覆盖率开关在 22.23.4 仍带 experimental |
| 进程模型 | I/O 服务用多进程。CPU 密集计算用 Worker 池 |
| 密码 | `scrypt` 在标准库里。`argon2` 不在 `node:crypto` 里 |

不要为了「最新」在没跑测试的情况下把生产切到 26。也不要把只在 22.23.4 上见过的实验 API 写成永久契约。`node:sqlite`、类型转换开关、`mock.timers` 都属于会变的部分。

选型写进仓库的一页说明里：Node 主版本、包管理器、测试命令、生产环境变量从哪来。后来的人不用从脚本里猜。


## 是什么

选型是一条可以核对的决定，不是口号。核对日期 2026-11-07。

| 决定 | 这一天 |
| --- | --- |
| 新服务 | 26 Lithium，Active LTS。上线前用 26 重跑测试 |
| 本教程已跑过的断言 | 22.23.4 Jod，Maintenance，支持到 2027-04-30 |
| Node 20 | 2026-04-30 已结束支持 |
| 直接 `node file.ts` | 只剥离可擦除语法，不检查类型。`enum` 要实验开关 |
| `node:sqlite`、`mock.timers`、类型转换 | 仍是实验能力，不写进长期契约 |
| HTTP | 标准库够做小服务。框架不改变事件循环 |
| 密码 | 标准库有 `scrypt`，没有 `argon2` |
| 进程 | I/O 用多进程。CPU 用 Worker 池 |

## 框架那一章在讲机制，不讲测速

路由树、洋葱模型、依赖注入见后面的三章。它们解释请求怎么被分发、错误怎么被接住、对象由谁创建。不要把未经这次测量的「快几倍」写进设计文档。

MCP 的远程传输以 2026-07-28 的 Streamable HTTP 为准，见[模型上下文协议](./19-模型上下文协议.md)。旧教程若只讲 2024 年的 HTTP+SSE，已经落后于这份规范。

## 本章问答

### 1. 为什么教程还写 22，却建议新服务看 26？

**考点：** 已核对和当前推荐不是同一句话。

**回答：** 示例在 22.23.4 上跑通，没有在 26 上跑。26 在这一天是 Active LTS，适合新服务，但要先重跑 `node examples/run-all.mjs`。没跑就切换，等于把未知当契约。

### 2. 哪些 API 不能写进长期设计？

**考点：** 实验标记。

**回答：** `node:sqlite`、`mock.timers`、`--experimental-transform-types`、覆盖率开关。稳定的是 `node:test`、`fetch`、`node:fs/promises`、权限模型的存在本身。实验 API 可以用来学习，调用处要有替换方案。

### 3. 包管理器算 Node 的一部分吗？

**考点：** Corepack 和 pnpm。

**回答：** npm 随 Node 提供。pnpm 不是语言运行时。Node 22 可能带 Corepack，但是否启用要在那台机器上看。安装用锁文件和冻结安装，见[包与版本](../01-入门/07-包与版本.md)。

## 事故复盘

没跑测试就把生产切到 Node 26。教程的断言只在 22.23.4 上通过，26 的代号是 Lithium，`examples/A/01-hello.mjs` 会失败。新服务可以选 26，但要先重跑 `run-all`。

把 `node:sqlite` 写进三年的架构说明。它在 22.23.4 仍打印实验警告。长期契约用稳定驱动，SQL 仍用占位符。

文档写「pnpm 是 Node 22 内置的」。它不是。是否有 Corepack 要在那台机器上确认。
