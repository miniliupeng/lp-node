正文：[限流](../04-工程与系统设计/08-限流.md)、[队列](../04-工程与系统设计/09-队列.md)、[系统设计](../04-工程与系统设计/14-系统设计.md)、[2026 选型](../04-工程与系统设计/15-2026选型.md)。

## 1

**题目：** 容量为 2、每秒补充 1 个的令牌桶，在 0ms 连续取三次、在 999ms 再取一次，结果是什么？多进程时限额还准吗？

**难度：** 进阶

**考察点：** 令牌桶的时间计算，以及进程内状态的范围。

**参考答案：** 0ms 的前两次成功，第三次失败。999ms 时补充量还不到 1，仍然失败。1000ms 成功一次。进程内的桶只限制该进程。副本数乘以单进程限额才是集群的实际上限。全局限额要把计数放到共享存储的原子更新里。`X-Forwarded-For` 只信任自己的代理。

**易错点：** 用「每分钟允许 N 次」的固定窗口，却没提窗口边界会放进两倍流量。令牌桶要讲清容量和补充速率。

## 2

**题目：** 可见性超时怎样实现至少一次投递？消费者要满足什么？

**难度：** 深入

**考察点：** 投递语义，而不是「用了 Redis 就可靠」。

**参考答案：** `pull` 把任务隐藏 `visibilityMs`。这段时间内别人看不到。只有 `ack` 才删除。处理者崩溃而没有 ack，超时后同一条任务会再次出现。示例在 0ms 取到、500ms 取不到、1000ms 又能取到。处理必须能重复执行，或用业务主键挡住重复。内存队列在进程退出后消失，不能当成生产消息系统。超时要长于正常处理时间。

**易错点：** 说「ack 之前别人绝对看不到，所以恰好一次」。隐藏到期之后就会再投递。

## 3

**题目：** 设计短链时，示例保证了什么，又明确做不到什么？

**难度：** 深入

**考察点：** 把教学实现和多实例方案分开。

**参考答案：** 单进程里，`POST /links?url=` 只接受 `http` 或 `https`，相同 URL 得到同一个 code，`GET /{code}` 回 302。code 是递增序号的 36 进制，存在内存 `Map`。做不到的是：进程重启后还在、多个实例共享、随机 code 的冲突处理、敏感地址的鉴权。生产要有共享存储上的唯一约束，跳转读多写少，可以缓存，数据库仍是事实来源。开放重定向要限制协议和长度。

**易错点：** 一上来选数据库，却说不清相同 URL 是否必须映射到同一个 code。

## 4

**题目：** 2026-11-07 新服务选哪条 Node 线？这个教程为什么仍写 22？

**难度：** 基础

**考察点：** 发布状态和「已核对」是两回事。

**参考答案：** 当天 26 是 Active LTS，更适合新服务，但上线前要用 26 重跑测试。22 处于 Maintenance，支持到 2027-04-30。本教程的断言在 22.23.4 上跑过，没有在 26 上跑过。20 已于 2026-04-30 结束支持。`node:sqlite`、`enum` 的类型转换和 `mock.timers` 仍是实验能力，不要写成永久契约。

**易错点：** 把教程里的 22.23.4 说成「2026 年唯一该用的版本」，或者没跑测试就把生产切到下一条 LTS。


## 5

**题目：** 依赖注入为什么能换成内存数据库？Node 的类型剥离为什么做不到靠装饰器自动注入？

**难度：** 深入

**考察点：** 显式依赖，以及元数据从哪来。

**参考答案：** 对象通过参数或令牌拿到依赖，测试登记另一个工厂即可。`examples/D/10-di.mjs` 里 `db` 是单例。`design:paramtypes` 来自 TypeScript 的 `emitDecoratorMetadata`，不是 `node file.ts` 的剥离结果。22.23.4 上没有这段元数据，容器就不知道构造函数要哪个类。

**追问：** 2026-07-28 的 MCP 远程传输还要单独开 GET SSE 吗？不要。每个 JSON-RPC 请求是一次 POST，响应才可能是 SSE。更早的修订才有独立 GET 流。

## 事故复盘

短链题一开始就画 Redis。没说相同 URL 是否必须同一个 code，也没说 302 会被用来做开放跳转。令牌桶题不提多进程放大限额。这些边界比组件名字更值钱。
