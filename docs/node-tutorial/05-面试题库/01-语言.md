# 语言

正文：[值与相等](../01-入门/02-值与相等.md)、[函数闭包与 this](../01-入门/03-函数闭包与this.md)、[集合与 JSON](../01-入门/04-集合与JSON.md)。

## 1

**题目：** `===` 和 `Object.is` 对 `NaN`、`+0`、`-0` 有什么差别？`typeof null` 是什么？

**难度：** 基础

**考察点：** 相等，以及不要用 `typeof` 判断 `null`。

**参考答案：** `NaN === NaN` 为 `false`，`Object.is(NaN, NaN)` 为 `true`。`+0 === -0` 为 `true`，`Object.is(+0, -0)` 为 `false`。`1 / -0` 是 `-Infinity`。`typeof null` 是 `"object"`，判断空值用 `value === null`。`assert.equal` 走 `Object.is`，所以它认为两个 `NaN` 相等。

**易错点：** 用 `x === NaN` 判断失败。源码里的字面量 `-0` 可能被格式化成 `0`，示例用 `Number('-0')`。

**追问：** 金额和主键为什么不用普通 `number`？超过 `Number.MAX_SAFE_INTEGER` 的整数不能精确表示。

## 2

**题目：** `??` 和 `||` 对 `0` 有什么不同？默认参数什么时候生效？

**难度：** 基础

**考察点：** 空值合并和默认参数的触发条件。

**参考答案：** `0 ?? 1` 是 `0`，因为 `??` 只在左侧是 `null` 或 `undefined` 时取右侧。`0 || 1` 是 `1`。默认参数只在实参是 `undefined` 时生效，传入 `0` 或 `null` 不会触发。

**易错点：** 用 `||` 给端口或数量兜底，把合法的 `0` 换成默认值。

**追问：** 可选链在哪停？中间是 `null` 或 `undefined` 时得到 `undefined`。它接不住右侧函数内部抛出的异常。

## 3

**题目：** ESM 里把对象方法拆出来再调用，会发生什么？

**难度：** 进阶

**考察点：** 严格模式下的 `this`。

**参考答案：** ESM 是严格模式。`box.method()` 的 `this` 是 `box`。箭头函数沿用定义时的 `this`。把方法拆成独立函数再调用，`this` 是 `undefined`，读 `this.n` 抛 `TypeError`。需要固定接收者时用 `bind`，或始终写 `box.method()`。

**易错点：** 把浏览器非严格脚本里的 `this === globalThis` 搬到 Node 模块里。

**追问：** 闭包抓住的大对象什么时候才能被回收？函数本身还被定时器或缓存引用时，对象就还在。

## 4

**题目：** `JSON.parse('{"__proto__":{"admin":true}}')` 之后，`admin` 在不在原型上？

**难度：** 深入

**考察点：** 22.23.4 上 `JSON.parse` 和原型污染的真正入口。

**参考答案：** 得到一个名叫 `"__proto__"` 的自有属性。`admin` 是 `undefined`，原型仍是 `Object.prototype`。原型污染发生在递归合并：代码看到这个键就去改了 `Object.prototype`。合并外部对象时跳过 `__proto__`、`prototype`、`constructor`，或用 `Object.create(null)` 当字典。

**易错点：** 声称 `JSON.parse` 本身会把 `__proto__` 设成对象的原型。在 22.23.4 上不是这样。

**追问：** `JSON.stringify` 怎么处理 `undefined`、`Date` 和 `bigint`？对象字段的 `undefined` 被丢掉，数组里的 `undefined` 变成 `null`，`Date` 变成 ISO 字符串，`bigint` 抛 `TypeError`。

## 5

**题目：** `structuredClone` 一个类实例，方法还在吗？

**难度：** 进阶

**考察点：** 结构化克隆的边界。

**参考答案：** 不在。示例里的 `Box` 克隆后是普通对象 `{ n: 3 }`，原型是 `Object.prototype`。它能复制普通对象、数组、`Date`、`Map`、`Set`，不复制函数。浅拷贝 `{ ...obj }` 只复制第一层。

**易错点：** 用克隆结果继续调用方法，运行时才发现 `double` 不是函数。


## 6

**题目：** `Promise.all`、`allSettled`、`race`、`any` 分别在什么时候拒绝？落选的那个停了吗？

**难度：** 进阶

**考察点：** 组合子，以及取消不是自动的。

**参考答案：** `all` 在第一个失败时拒绝。`allSettled` 不拒绝。`race` 采用最先落定的结果，失败也算。`any` 在全部失败时抛 `AggregateError`。落选的 Promise 继续执行。要停就传 `AbortSignal`。示例 `examples/A/15-promise-combinators.mjs`。

**易错点：** 说 `race` 会取消慢的那一个。

**追问：** 一万个任务直接 `all` 会怎样？全部立刻启动，连接和内存按任务数涨。用有上限的池，见[手写题](./11-手写题.md)。

## 事故复盘

白板题用 `==` 比较端口，`"0"` 被当成合法。接着用 `Partial` 描述创建参数，必填字段消失。语言题要落到 `===`、`Object.is`、`??` 和白名单，而不是背工具类型的名字。
