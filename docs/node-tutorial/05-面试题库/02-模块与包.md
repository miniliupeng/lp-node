# 模块与包

正文：[模块](../01-入门/06-模块.md)、[包与版本](../01-入门/07-包与版本.md)、[循环依赖](../03-运行时/12-循环依赖.md)、[权限与类型剥离](../03-运行时/14-权限与类型剥离.md)。

## 1

**题目：** `.mjs` 和 `.cjs` 各有什么加载规则？怎么从 ESM 调用 CJS？

**难度：** 基础

**考察点：** 模块格式由扩展名决定，不靠猜。

**参考答案：** `.mjs` 按 ESM，`.cjs` 按 CommonJS。`.js` 才看最近的 `package.json` 是否 `"type": "module"`。ESM 用 `createRequire(import.meta.url)` 加载旁边的 CJS。22.23.4 有 `import.meta.dirname` 和 `import.meta.filename`。内置模块写 `node:fs` 这种前缀。

**易错点：** 在 ESM 里使用 `__dirname`，那是 CJS 的变量。

**追问：** 同一个模块 URL 评价失败之后再导入，会重试吗？不会，失败也被缓存。

## 2

**题目：** Node 22 里 `require()` 可以加载 ESM 吗？什么情况下不行？

**难度：** 进阶

**考察点：** `require(esm)` 的同步限制。

**参考答案：** 22.23.4 上 `process.features.require_module === true`。CJS 的 `require()` 可以同步加载没有顶层 `await` 的 ESM，得到模块命名空间。示例对本地 ESM 调用 `mul(2, 6)` 得到 12。有顶层 `await` 时同步 `require` 等不了，改用动态 `import()`。

**易错点：** 说「Node 永远不能 require ESM」，这在 22.23.4 上已经过时。也不要说所有 ESM 都能同步 require。

## 3

**题目：** ESM 循环依赖时，什么时候会 `ReferenceError`？CJS 呢？

**难度：** 深入

**考察点：** 活绑定和暂时性死区。

**参考答案：** ESM 导出是活绑定。初始化期间直接读取对方尚未初始化的 `const`，得到 `ReferenceError`。如果只是导出函数，两边都初始化完再调用，就能读到已经赋好的值。示例 `fromB()` 返回 `{ bName: 'module-b', seen: 'module-a' }`。CJS 导出的是对象属性，循环进行中只能看到当时已经挂上的字段。示例里 `b` 初始化时 `a.done` 仍是 `false`，结束后 `a` 能看到 `b.done === true`。

**易错点：** 背「循环依赖一定得到空对象」。两种模块不一样。

## 4

**题目：** `^1.2.3` 接受哪些版本？`^0.2.3` 为什么不能照同一个规则解释？

**难度：** 进阶

**考察点：** 语义化版本，以及 0.x 的特殊范围。

**参考答案：** 主版本大于等于 1 时，`^1.2.3` 接受大于等于 1.2.3 且小于 2.0.0 的版本，`~1.2.3` 只接受小于 1.3.0 的补丁。npm 对 `^0.2.3` 只允许补丁升级，示例故意对 `^0.x` 抛错，避免把 1.x 的规则套上去。应用仓库提交锁文件。

**易错点：** 认为插入符在 0.x 和 1.x 上意思相同。

## 5

**题目：** `node app.ts` 会做类型检查吗？`enum` 能直接跑吗？

**难度：** 深入

**考察点：** 类型剥离和类型检查是两件事。

**参考答案：** 22.23.4 上 `process.features.typescript === "strip"`。可擦除的类型注解会被去掉，示例打印 `5`。Node 不做类型检查。`enum` 不是可擦除语法，直接运行得到 `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`。加上 `--experimental-transform-types` 才能跑，并打印实验警告。`using` 在这个版本是语法错误。类型检查用 `tsc --noEmit`。

**易错点：** 把「能跑」当成「类型是对的」。


## 6

**题目：** 什么是幽灵依赖？pnpm 的目录为什么能挡住它？

**难度：** 进阶

**考察点：** 提升、内容寻址存储、符号链接。

**参考答案：** npm 扁平化后，没在自己 `package.json` 里声明的包也可能被解析到。pnpm 把内容放进全局存储，用硬链接复用，顶层 `node_modules` 只给直接依赖放符号链接。没声明的名字解析失败。CI 用冻结锁文件安装。pnpm 不是 Node 内置的包管理器。

**易错点：** 只回答「pnpm 更快」，不提隔离。

**追问：** `^0.2.3` 能不能按 `^1.2.3` 的规则解释？不能。0.x 的插入符在 npm 里只允许补丁。

## 事故复盘

回答「CJS 是拷贝，所以改了对方一定看不见」。对象字段是共享的。接着说 pnpm 只是更快，没提幽灵依赖。这题会停在 1 分。补上活绑定、`require(esm)` 的顶层 await 限制，以及 0.x 插入符。
