# 异步

示例：`examples/A/10-async.mjs`

Promise 有三种状态：pending、fulfilled、rejected。状态只走一次。`async` 函数总是返回 Promise。`return 1` 让它完成成 1，`throw` 或 `await` 到拒绝让它拒绝。

`await` 暂停这个函数，主线程可以去跑别的已就绪回调。它不是线程睡眠。长时间的同步循环才会挡住同一进程里的其他请求。

`Promise.withResolvers()` 在 22.23.4 可用，返回 `{ promise, resolve, reject }`，用来把回调 API 包成 Promise。自己写 `new Promise` 时每个分支只结算一次，`reject` 传入 `Error`。

`Promise.all` 在任一拒绝时拒绝，适合缺一不可的读取。`Promise.allSettled` 等全部结束，每项带 `status`。示例里一项成功、一项失败，`allSettled` 两条都留下，`all` 则拒绝。

`Promise.race` 采用最先落定的那个，其余仍会在后台继续。要停掉它们，传同一个 `AbortSignal`。

创建了 Promise 却不 `await`、也不 `catch`，一旦拒绝，Node 22 默认让进程退出。见[拒绝与取消](../03-运行时/13-拒绝与取消.md)。队列的精确顺序不要在这一章背口诀，[任务队列](../03-运行时/03-任务队列.md)有断言。


## 是什么

Promise 有三种状态：pending、fulfilled、rejected。状态只走一次。`async` 函数总是返回 Promise。`await` 暂停的是这个函数，不是线程。主线程可以去跑别的已就绪回调。

## 四个组合子

示例 `examples/A/15-promise-combinators.mjs` 覆盖了后两个。`all` 和 `allSettled` 在 `examples/A/10-async.mjs`。

| 方法 | 完成 | 拒绝 | 适合 |
| --- | --- | --- | --- |
| `Promise.all` | 全部成功 | 第一个失败就拒绝，其余仍会跑完 | 缺一不可 |
| `Promise.allSettled` | 永远等到全部落定 | 不拒绝 | 允许部分失败 |
| `Promise.race` | 第一个落定，不论成败 | 同左 | 和超时赛跑 |
| `Promise.any` | 第一个成功 | 全部失败才拒绝，错误是 `AggregateError` | 多个来源谁先成功用谁 |

`race` 和 `any` 不会取消落选的那几个。它们继续占连接。要停掉它们，传同一个 `AbortSignal`。

`Promise.withResolvers()` 在 22.23.4 可用，用来把只会回调一次的 API 包成 Promise。自己写 `new Promise` 时每个分支只结算一次，`reject` 传入 `Error`。

## 为什么不能一次 all 一万个任务

`Promise.all(items.map(fn))` 会立刻调用全部 `fn`。文件描述符、数据库连接和内存会一起耗尽。上限见 `examples/E/01-pool.mjs`：同时只跑 `limit` 个，结果按下标写回，顺序和输入一致。

队列的精确顺序不要在这一章背口诀。[任务队列](../03-运行时/03-任务队列.md)有断言。浮空的拒绝会让进程退出，见[拒绝与取消](../03-运行时/13-拒绝与取消.md)。

## 本章问答

### 1. all、allSettled、race、any 各在什么时候拒绝？

**考点：** 四个组合子。

**回答：** `all` 在第一个失败时拒绝。`allSettled` 不拒绝，每项带 `status`。`race` 采用最先落定的那个，失败也算落定。`any` 只要有一个成功就成功，全部失败才抛 `AggregateError`，里面有 `errors` 数组。落选的 Promise 不会被自动取消。

### 2. await 是不是把线程睡了？

**考点：** 让出的是调用栈。

**回答：** 不是。`await` 把函数的后半段排进微任务，主线程去跑别的回调。真正挡住所有人的是同步循环、`readFileSync` 和同步加密。

### 3. 为什么一万个并发会把进程打爆？

**考点：** `all` 没有上限。

**回答：** `map` 立刻把每个任务都启动了。套接字和内存按任务数涨，不按「你以为的并发度」涨。用固定数量的 worker 取任务，或在队列满时拒绝新任务。手写见[手写题](../05-面试题库/11-手写题.md)。

## 事故复盘

`Promise.all(urls.map(fetch))` 在一次请求里打开了几千个连接，进程报打开文件过多。`all` 没有并发上限。改成 `examples/E/01-pool.mjs` 这种固定数量的 worker。

超时用 `Promise.race` 和一个定时器实现，超时之后仍去写数据库，因为原来的 `fetch` 没有 `AbortSignal`。`race` 只忽略后到的结果，不取消工作。

`Promise.any` 全部失败时抛 `AggregateError`。只看 `error.message` 会错过里面的 `errors` 数组，日志里没有真正的原因。示例 `examples/A/15-promise-combinators.mjs` 断言了这个类型。
