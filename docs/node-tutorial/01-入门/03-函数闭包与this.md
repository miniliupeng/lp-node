# 函数、闭包与 this

示例：`examples/A/03-functions.mjs`

闭包让返回的函数继续使用外层的 `let`。`makeCounter` 每次调用得到独立的 `n`，连续三次返回 1、2、3。被闭包抓住的大对象会跟函数一样长寿。定时器如果抓住请求体，请求结束后内存仍在。

ESM 是严格模式。`box.method()` 的 `this` 是 `box`。方法内部的箭头函数沿用这个 `this`。把方法拆出来再调用，`this` 是 `undefined`，读 `this.n` 抛 `TypeError`。要固定接收者就 `bind`，或者始终写成 `box.method()`。

默认参数只在实参是 `undefined` 时生效。`0` 和 `null` 不会触发它。

`??` 只在左侧是 `null` 或 `undefined` 时取右侧，所以 `0 ?? 1` 是 `0`。`||` 会把 `0` 当成假而换成右侧。数量和端口用 `??`。

可选链在中间为 `null` 或 `undefined` 时得到 `undefined`，不再往下读。它不能拦住右侧函数内部抛出的异常。

对象解构 `const { name, ...rest } = user` 是浅拷贝。


## 是什么

函数是一等值。闭包是函数加上它定义时所见的绑定。`this` 由调用方式决定，不由定义位置决定。箭头函数没有自己的 `this`，沿用外层。

## 为什么会泄漏或丢接收者

定时器、事件监听器如果抓住了请求体或数据库行，请求结束后这些对象仍然活着。把对象方法拆出来交给 `forEach` 或定时器，严格模式下 `this` 是 `undefined`，读字段就抛 `TypeError`。ESM 文件整个都是严格模式，没有浏览器非严格脚本里那种 `this === globalThis`。

## 调用方式

| 写法 | `this` |
| --- | --- |
| `box.method()` | `box` |
| `const fn = box.method; fn()` | `undefined`（严格模式） |
| 箭头函数 | 定义时外层的 `this` |
| `fn.call(box)` / `fn.apply(box)` | 你传入的那个值 |
| `fn.bind(box)` | 固定为 `box`，之后再 `call` 也改不掉 |

默认参数只在实参是 `undefined` 时计算，每次调用重新计算。`null` 不会触发默认值。

`??` 只把 `null` 和 `undefined` 当成空。`||` 还会把 `0`、`''`、`false` 换掉。数量、端口、布尔开关用 `??`。

可选链 `a?.b` 在 `a` 是 `null` 或 `undefined` 时短路。它不捕获 `b` 是函数时函数内部抛出的错误。

## 本章问答

### 1. 闭包为什么会把内存留住？

**考点：** 可达性，不是「闭包一定泄漏」。

**回答：** 被内层函数引用的绑定，要等内层函数本身不可达才回收。若这个函数进了全局缓存、`setInterval` 或 `EventEmitter`，外层的大对象就一直在。处理请求时不要把整个 `req` 放进长期定时器，只拷贝需要的 id。

**易错：** 把所有闭包都当成泄漏。函数返回后没有人再引用它，闭包可以回收。

### 2. 为什么解构出来的方法一调用就炸？

**考点：** `this` 由调用点决定。

**回答：** `const { method } = box; method()` 没有接收者。严格模式下 `this` 是 `undefined`。修法是 `box.method()`，或 `method.call(box)`，或在构造时就把箭头函数挂到实例上。`bind` 适合回调只收到函数、不收到对象的 API。

### 3. `||` 和 `??` 写配置时选哪个？

**考点：** 合法的假值。

**回答：** 允许 `0` 和空字符串的配置用 `??`。只有「空就用默认文案」这种真的想丢掉空字符串的场景才用 `||`。默认参数同样不把 `null` 当成缺省。

## 事故复盘

把 `logger.write` 传给 `stream.on('data', logger.write)` 之后，`write` 里的 `this` 不是 logger。严格模式下这是 `TypeError`，流的 `error` 若没人听，进程退出。回调改成箭头函数，或 `logger.write.bind(logger)`。

缓存函数记住了整个请求体以便「稍后重试」。请求结束后内存不降。缓存里只放 id 和可重建的参数，不要放 `req`。

默认参数写成 `function page(n = getPage())` 时，每次没传 `n` 都会调用 `getPage()`。它不是只在启动时算一次。有副作用的默认值要知道这一点。

### 再答一题

**题目：** 可选链能不能代替校验？

**回答：** 不能。`user?.name` 在 `user` 为空时得到 `undefined`，程序会带着空名字继续写库。校验要拒绝这种输入并返回 400。可选链只适合展示层避免抛错，不适合作为边界。
