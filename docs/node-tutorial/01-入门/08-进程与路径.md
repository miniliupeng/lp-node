# 进程与路径

示例：`examples/A/08-path-process.mjs`

`process.cwd()` 是启动 `node` 时的工作目录。`fs.readFile('a.txt')` 相对它，不是相对源文件。模块旁边的文件用 `import.meta.dirname` 再 `path.join`。

`process.env` 的值都是字符串，缺失的键是 `undefined`。`process.exit(1)` 立刻结束，排队的回调不再跑。更常见的是设置 `process.exitCode = 1`，让事件循环把收尾做完。

`path.join` 会处理 `..`。`path.resolve('/var/app', '/etc/passwd')` 得到 `/etc/passwd`，因为第二个绝对路径替换了前面的部分。这就是把用户输入拼进根目录会逃逸的原因。

示例的检查：

1. `path.resolve(root, userPath)`
2. `path.relative(root, resolved)`
3. 相对路径以 `..` 开头，或变成绝对路径，就拒绝

`a/b.txt` 通过，`../etc/passwd` 和 `/etc/passwd` 拒绝。这是 POSIX 上的字符串检查。目录里如果有指向外部的符号链接，打开文件后再用真实路径查一次。

临时文件放在 `os.tmpdir()`，用 `fs.mkdtemp` 建独占目录，用完删除。


## 是什么

路径是字符串，不是已经打开的文件。`path.join` 和 `path.resolve` 只做字符串归一化，不访问磁盘，也看不见符号链接。工作目录 `process.cwd()` 是启动 node 时的目录，不是源文件所在目录。

## 为什么用户输入不能直接拼接

`path.resolve('/var/app', '/etc/passwd')` 得到 `/etc/passwd`，因为后一个绝对路径替换了前面的部分。`../` 会走出根目录。只搜索字符串里有没有 `..` 会误伤合法的 `a/../b.txt`，又放行以绝对路径传入的地址。

正确顺序：

1. `path.resolve(root, userPath)`
2. `path.relative(root, resolved)`
3. 相对结果以 `..` 开头，或是绝对路径，就拒绝

示例 `examples/A/08-path-process.mjs` 和 `examples/D/08-safe-path.mjs` 断言了通过和拒绝的情况。这仍是字符串检查。根目录里如果有指向外部的符号链接，打开之后还要用 `fs.realpath` 再查一次。

## 环境和退出码

`process.env` 的值全是字符串，缺键是 `undefined`。`process.exit(1)` 立刻结束，排队的回调不再跑。设置 `process.exitCode = 1` 让事件循环把收尾做完再退出。

临时文件放在 `os.tmpdir()`，用 `fs.mkdtemp` 建独占目录，`finally` 里删除。不要用可预测的固定文件名，并发测试会互相覆盖。

## 本章问答

### 1. `join` 和 `resolve` 差在哪？

**考点：** 绝对路径的替换规则。

**回答：** `join` 把片段接起来并处理 `.` 和 `..`。`resolve` 从右往左看，遇到绝对路径就丢掉左边，再相对当前工作目录补全。所以把用户输入放进 `resolve(root, input)` 时，输入如果以 `/` 开头，`root` 会消失。

### 2. 工作目录和模块目录为什么要分开？

**考点：** 相对路径的基准。

**回答：** `readFile('a.txt')` 相对 `process.cwd()`。模块旁边的文件用 `import.meta.dirname` 再 `path.join`。测试从别的目录启动时，这两种相对路径指向不同的地方。

### 3. 字符串检查为什么挡不住符号链接？

**考点：** 路径归一化和文件系统不是一回事。

**回答：** `path` 不看磁盘。`root/link` 如果是指向 `/etc` 的符号链接，字符串上它仍在 `root` 里面。打开文件后用真实路径再判断一次，真实路径仍然要落在允许的根里。

## 事故复盘

下载接口把查询参数直接拼进 `path.join(root, name)`。`name` 为 `../../etc/passwd` 时，字符串走出了根目录。`path.resolve(root, name)` 在 `name` 以 `/` 开头时还会把 `root` 整个丢掉。先 `resolve`，再看 `path.relative` 是否以 `..` 开头或变成绝对路径。示例 `examples/D/08-safe-path.mjs` 覆盖了这几种输入。

符号链接仍能逃出这个检查。`root/link` 指向 `/etc` 时，字符串上它在根内。打开后用 `realpath` 再判断一次。

测试从仓库根启动，代码用 `cwd` 去读模块旁边的夹具，换个目录跑就 `ENOENT`。模块旁边的文件用 `import.meta.dirname`。

### 再答一题

**题目：** `process.exit` 和 `exitCode` 怎么选？

**回答：** `exit` 立刻结束，定时器和关闭回调都不跑。设置 `exitCode` 让循环把已登记的收尾做完。致命且确定没有在途工作的启动失败，可以在 `listen` 之前退出。接流量之后不要用 `exit` 当第一反应。
