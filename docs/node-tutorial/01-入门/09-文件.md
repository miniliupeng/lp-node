# 文件

示例：`examples/A/09-fs.mjs`

新代码用 `node:fs/promises`。

```javascript
const dir = await mkdtemp(join(tmpdir(), 'lp-node-fs-'));
const file = join(dir, 'note.txt');
await writeFile(file, 'hello\n', 'utf8');
const text = await readFile(file, 'utf8');
await rm(dir, { recursive: true, force: true });
```

不传 `'utf8'` 时 `readFile` 返回 `Buffer`。文件不存在的 `code` 是 `ENOENT`。

`readFile(file, { signal })` 可以中止。示例在调用前 `abort()`，错误是 `AbortError` / `ABORT_ERR`。请求取消时把同一个信号传给文件和网络，避免后台继续做完。

`readFileSync` 占住主线程。启动时读一份小配置可以说得通。HTTP 请求路径上读大文件要用异步 API，更大的文件用流，见[流与背压](../02-进阶/02-流与背压.md)。不要把整个大文件读进一个字符串再写给响应。

示例把目录放在 `try/finally` 里，断言失败也会删掉。


## 是什么

`node:fs/promises` 把 libuv 的文件操作包成 Promise。不传编码时读到的是 `Buffer`。传 `'utf8'` 才得到字符串。文件不存在的 `code` 是 `ENOENT`，权限不够是 `EACCES`。

## 为什么请求路径上不能 readFileSync

`readFileSync` 占住 JavaScript 主线程，这段时间里定时器、网络回调都不会跑。启动时读一份小配置可以说得通。每个 HTTP 请求读大文件要异步，更大的文件用流，见[流与背压](../02-进阶/02-流与背压.md)。不要把整个大文件读成一个字符串再写给响应。

## 中止和清理

`readFile(file, { signal })` 在信号已经 abort 时拒绝，名称 `AbortError`，代码 `ABORT_ERR`。请求取消时把同一个信号传给文件和网络，避免后台继续读完。

示例用 `mkdtemp` 建目录，`try/finally` 里 `rm` 掉。断言失败也会清理。直接 `writeFile` 到目标路径，写到一半崩溃会留下半个文件。替换已有文件用同一目录里的临时文件再 `rename`，见[原子替换文件](../02-进阶/03-原子替换文件.md)。

`fs.watch` 的事件在不同操作系统上粒度不同，可能重复、可能合并。不要用它做「恰好收到一次」的业务队列。

## 本章问答

### 1. 不传编码时 readFile 返回什么？

**考点：** 字节和字符串。

**回答：** 返回 `Buffer`。传 `'utf8'` 才解码成字符串。把 `Buffer` 当字符串去 `JSON.parse` 会失败，或者先按默认 UTF-8 解码出替换字符。非法的 UTF-8 不会抛错，会被替换。

### 2. 已经 abort 的信号再去读文件，错误长什么样？

**考点：** 错误码。

**回答：** `name` 是 `AbortError`，`code` 是 `ABORT_ERR`。用 `code` 分支，不要比较英文句子。示例 `examples/A/09-fs.mjs` 在调用前就 `abort()`，所以不会真的把文件读完。

### 3. 什么时候可以用同步文件 API？

**考点：** 主线程预算。

**回答：** 进程启动、还没接流量的时候，读一小份配置。接流量之后的请求路径用 promises 或流。同步 API 的方便来自它挡住了所有其他连接。

## 事故复盘

请求处理函数里 `readFileSync` 读用户上传的导出文件。文件有 200MB 时，主线程停住，健康检查超时，编排系统把实例杀掉。大文件改成流，并在读之前限制大小。启动时读一份几 KB 的配置仍可以用同步 API。

`readFile` 不传编码，后面把结果当字符串去 `startsWith`。`Buffer` 的 `startsWith` 可以接受字符串，但后续拼接会把字节和字符串混在一起。要文本就显式传 `'utf8'`。

清理放在 `try` 的成功分支里，断言一失败临时目录就留下。示例把 `rm` 放在 `finally`。已经中止的信号再读文件，得到 `ABORT_ERR`，不要当成 `ENOENT` 去创建文件。
