# D04 HTTP API

路由形状见 [`B/06-http-router.mjs`](../../../examples/node-tutorial/B/06-http-router.mjs)。

## 状态码

| 码 | 用在 |
| --- | --- |
| 200 | 读成功，正文有表示 |
| 201 | 创建成功。示例短链返回 201 和 `{ code }` |
| 204 | 成功且没有正文 |
| 301 / 302 | 资源改了位置。短链示例用 302，表示跳转目标可以以后改 |
| 400 | 请求语法或字段不合法 |
| 401 | 没有认证 |
| 403 | 已认证但没有权限 |
| 404 | 没有这个资源 |
| 409 | 和当前状态冲突，例如重复创建了不允许重复的键 |
| 413 | 正文超过限制 |
| 429 | 超过速率限制 |
| 500 | 服务器没有处理好。不要用 500 表示用户填错了表单 |

错误正文用稳定形状：`{ "error": { "code": "E_NAME", "message": "..." } }`。`code` 给程序，`message` 给人。示例为了短，只用了 `{ error: string }`。

## 幂等

`GET`、`PUT`、带条件的删除，重复执行不应产生第二份副作用。`POST` 创建默认不是幂等的。支付、下单这类接口接受客户端生成的 `Idempotency-Key`，服务器记下键和第一次的响应，同样的键再来就返回第一次的结果。键要和用户身份一起存，避免别人复用你的键。

重试（B07）只对幂等请求或带幂等键的请求自动进行。

## 分页

列表接口返回上限，例如 `limit` 默认 20、最大 100。用“创建时间加主键”做游标，避免 `OFFSET` 在大表上越翻越慢。响应里给出下一页游标，没有下一页时为空。

## 超时与正文

每个路由有正文大小上限（示例是 32 字节，只为演示 413）。出站调用有超时。路由函数不要做无界循环。

## 自测

1. 用户把年龄写成字符串，应该返回哪一类状态码？400，并指出字段。
2. 为什么短链用 302 而不是把目标正文代理回来？302 让客户端直接去目标，短链服务不必转发流量。目标不应被客户端缓存死时，302 比 301 合适。
3. 幂等键存在哪里？存在服务端，和用户身份一起，并有过期时间。
