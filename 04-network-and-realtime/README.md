# 阶段 04: 网络编程与实时通信通信

网络是后端的血液。现代 Web 框架（Express / Fastify / Koa）虽然封装了极佳的开发者体验，但在大厂面试或深入排查生产网络疑难杂症（如 TCP 假死、连接泄露、长连接保活）时，**原生网络原语是唯一的救命稻草**。

---

## ☕ 生活化心智：信使与电话专线

1. **原生 HTTP/1.1 服务**：
   - 就像**寄明信片**。客户端寄出一张写有地址（URL）和内容（Body）的明信片，服务器盖章（Status Code）后回寄一张明信片，每次通信都要来回折腾一次。
   - `req` 本质上是一个**可读流（Readable）**，`res` 本质上是一个**可写流（Writable）**。
2. **TCP Socket 通信与粘包**：
   - 就像**一条不停流动的运输传送带**。TCP 是“面向字节流”的协议，它根本不知道你的业务消息在哪里开头、在哪里结尾。
   - 你连续放上去 3 块小积木（发送 3 个小数据包），传送带可能会把它们挤在一起运到对面（**粘包**），或者把一块积木切成两半运过去（**半包**）。
3. **WebSocket 长连接与心跳保活**：
   - 就像**两个人拿起电话筒不挂断（专线通话）**。但如果中间的电信基站或交换机悄悄断线了，双方拿着听筒并不知道对方已经听不见了（僵尸假死连接）。
   - 因此双方必须每隔几秒互相发送一次简短的“喂？还在吗？”（**Ping/Pong 心跳探针**），一旦三次呼叫无应答，立即主动挂断并重新拨号（重连）。
