# 阶段 00: 现代工程工具链与开发基石

工欲善其事，必先利其器。在深入 Node.js 底层与架构之前，我们必须先理清现代 Node.js 后端工程的工具链心智：**如何以最轻量、最现代、最快的方式编写和运行 TypeScript 代码**。

---

## ☕ 生活化心智：搭积木与工具箱

如果我们把写 Node.js 后端比作**开一家现代化咖啡馆**：
1. **Node.js 运行时**：就像咖啡馆的中央操作台与主电网，提供运转水、电和单线程服务员的基础设施。
2. **pnpm 包管理器**：就像中央集采仓库。传统 npm 是每开一家分店都把所有咖啡豆复制一份（磁盘巨占）；pnpm 则是总仓存放一份，各店使用“取货二维码”（硬链接）直接取用，极速且省地。
3. **TypeScript + tsx**：就像带配方质检的智能点单屏。以前用纯 JS 容易漏写糖分剂量（运行时才报错）；现在在点单瞬间就能标出语法红线，且 tsx 让你按下回车立即出单，不需要漫长烘焙打包。
4. **Native Test Runner**：操作台出厂自带的微型测温计，不再需要从外界买一套笨重的第三方仪器，直接验证咖啡品质。
5. **环境变量治理**：相当于咖啡馆的私密保险箱密码。绝不能把密码写在菜单板上（禁止硬编码），要通过加密配置箱安全注入。
